# Personal Site

A static site built with Eleventy, Tailwind CSS, and Bun.

## Setup

1. Install dependencies: `bun install`
2. Install the Python build tools (Pillow and fontTools): `bun run setup:python`
3. Run dev server: `bun run start`
4. Build for production: `bun run build:prod`
5. Clean output: `bun run clean`

The Python environment lives in `.venv/` (ignored by Git). CI installs the same
packages from `requirements.txt` on every build.

## Directories

- Input: `src/`
- Output: `build/`
- CSS: `src/css/input.css` → `build/css/style.css`

## Metadata

`src/_data/site.json` is the shared source for the public name, site description,
social profiles, contact address, default social image, and saved-site manifest.
Both the personal and research Eleventy builds read it. The Python OG-image
generator reads the same file, so image captions cannot retain an old identity.

Page frontmatter `description` overrides the shared defaults. Home and About use
the site description; pages without a description use a relevant section default
or a paper-title fallback before falling back to the site description. Changing
metadata does not rewrite article bodies or article leads.

`scripts/site-metadata.mjs` resolves metadata and constructs JSON-LD objects.
`jsonLdScript` serializes them as script-safe JSON, not HTML-escaped text. Do not
interpolate quoted frontmatter directly into JSON-LD or infer employment and
graduation status from an old biography.

The manifest is generated by `src/site.webmanifest.11ty.js`. Social PNGs are
generated during the production build; do not edit generated images or `build/`.
After changing metadata, run `bun run check`, the research app's `bun run check`,
and `bun scripts/check-metadata.mjs --research`. Search engines and social
platforms can retain cached previews after deployment.
